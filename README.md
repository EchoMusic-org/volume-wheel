# 滚轮音量调节

增强 EchoMusic 主播放栏和歌词页底部控制栏的音量按钮交互：

- **悬停弹出**：鼠标移到音量按钮上即弹出音量条，移开后自动隐藏（原为点击弹出）。
- **点击静音**：点击音量按钮切换静音/取消静音，恢复时回到静音前的音量。
- **滚轮调节**：在音量按钮上滚动滚轮，按步进直接调节音量，无需打开音量条。

## 安装

1. 将整个 `volume-wheel` 目录放入 EchoMusic 的插件目录。应用内的插件管理页可以直接打开该目录；Windows 下通常为 `%APPDATA%\EchoMusic\plugins`。
2. 在插件管理页刷新插件列表，然后启用“滚轮音量调节”。

## 设置

- **每格滚轮调节步进**：1% - 20%，默认 5%。
- **反转滚轮方向**：系统自然滚动或滚轮方向与预期相反时开启。

## 实现说明

- 主播放栏和歌词页控制栏共用同一个音量组件，插件通过音量按钮的无障碍标签定位，因此两种页面使用同一套逻辑。
- 插件在捕获阶段处理滚轮并阻止事件继续传播，避免与宿主音量弹出层原有的滚轮逻辑叠加。
- 触控板的小幅滚动会累积到 100 像素后再调整一次，鼠标滚轮则通常每格调整一次。
- 悬停弹出/移开隐藏通过监听鼠标进出并向触发按钮派发合成点击实现，开合状态从触发器的 `aria-expanded` 读取；进出按钮与弹层各留 100ms 缓冲，穿过两者之间的空隙不会闪关。
- 点击静音只劫持用户真实点击（`isTrusted`），插件派发的合成点击会被放行用于开合弹层；静音切换复用宿主 `toggleMute`，带音量记忆。
