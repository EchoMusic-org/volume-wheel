# 滚轮音量调节

在 EchoMusic 主播放栏或歌词页底部控制栏的音量按钮上滚动鼠标滚轮，即可按步进调节播放器音量。

## 安装

1. 将整个 `volume-wheel` 目录放入 EchoMusic 的插件目录。应用内的插件管理页可以直接打开该目录；Windows 下通常为 `%APPDATA%\EchoMusic\plugins`。
2. 在插件管理页刷新插件列表，然后启用“滚轮音量调节”。

## 设置

- **每格滚轮调节步进**：1% - 20%，默认 5%。
- **反转滚轮方向**：系统自然滚动或滚轮方向与预期相反时开启。

## 实现说明

- 主播放栏和歌词页控制栏共用同一个音量组件，插件通过音量按钮的无障碍标签定位，因此两种页面使用同一套逻辑。
- 插件在捕获阶段处理滚轮并阻止事件继续传播，避免与宿主音量弹出层原有的滚轮逻辑叠加。
- 触控板的小幅滚动会累积到 100 像素后再调整一次，鼠标滚轮则通常每格调整一次。
